# splash-annual-report — 水花年报

Source: 小夕素材(31).pptx · 30 slides · 16:9. 英文商务年报模版 ("MORIMOTO Business Annual Report")。
深炭底封面/章节页 + 液体飞溅摄影（蓝色水花 × 熔金铜色）+ 白底内容页 + 蓝紫渐变 UI 卡片。
SaaS 产品感强, 数据/团队/里程碑页型齐全, 适合年报、融资、产品汇报。

## Design tokens

| Token | Value | Use |
|---|---|---|
| `--charcoal` | `#24242B` | 封面/章节页底 |
| `--copper` | `#7E736C` | 熔金水花的铜金调 (摄影自带) |
| `--paper` | `#FFFFFF` | 内容页底 |
| `--blue-grad-a` | `#5E6EDB` | UI 渐变起点 (按钮/卡片/进度) |
| `--blue-grad-b` | `#6A86DB` | UI 渐变终点 |
| `--navy` | `#353979` | 深蓝强调/深色卡 |
| `--coral-chip` | `#D96A7B` | 日期角标/次强调 (August 18 式) |
| photo treatment | 液体飞溅 (蓝水+金铜) 出血穿插; 内容页照片常规彩色 | |

Type: 加宽字距英文小标 "EDIT TITLE HERE" + 粗黑标题; 章节页 "PART ONE" 特大白字。
UI 语言: 圆角卡片、渐变按钮、进度条、评分星、日期角标——组件全部可编辑。
