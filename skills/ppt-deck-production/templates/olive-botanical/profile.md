# olive-botanical — 橄榄植物编辑部

Source: 小夕素材(13).pptx · 29 slides · 16:9. Cream-greige canvas + olive green blocks +
botanical photography ("Cloverie"): 温柔、自然、呼吸感。大写单词与图块错位叠放是标志手法。

## Design tokens

| Token | Value | Use |
|---|---|---|
| `--greige` | `#EAE6E2` | default canvas |
| `--olive` | `#97987C` | signature block color, display words, bands |
| `--olive-deep` | `#66684B` | dark accents, small labels |
| `--olive-soft` | `#C0BEAE` | secondary tint, palette strips |
| `--sage-mist` | `#BEC0A3` | light tint fills |
| `--ink` | `#2A2A26` | body text |
| photo treatment | 植物/绿植/花卉/人像与绿叶同框, 柔光低饱和 | all frames |

Type: grotesque titles; signature move = giant olive display word (可竖排/与照片交叠出血)。
Layout rhythm: 色块与照片错位拼贴, 一页一个大词。

## 推荐三级字体方案（fonts/ 库）

- 封面: 得意黑 · 标题: 阿里巴巴普惠体 Bold · 正文: 霞鹜文楷（文艺）或 阿里巴巴普惠体
- 中式自然向备选: 封面 演示夏行楷

## Element families

- `cover/title-system` — full-bleed olive field + light-streak texture + wordmark
- `section/divider` — giant olive display word overlapping small photo (or vertical word)
- `body/image-plus-text` — photo one side + olive block tail, title + short copy other side
- `body/color-palette` — palette strip row (取色页可改为品牌色展示组件)
- `statement/quote-block` — olive block with reversed white quote text
- `card/team-band` — portraits row sitting on olive band, names in band
- `chart/number-steps` — 01-04 数字节点 + 图标格 (slide26 式)
- `media/device-mockup` — laptop/phone raster + short caption + social icon row
- `chrome/page` — tiny vertical side label + page micro-caption
- `decorative/block-system` — olive rectangles anchoring photos; 出血到页边
