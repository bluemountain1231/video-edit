# y2k-marquee-white — 白底Y2K跑马灯

Source: 小夕素材(29).pptx · 20 slides · 16:9. 中文创意活动策划模版。
白底 + 四边跑马灯文字边框（循环小字）+ 黑细描边框 + 全息铬金属 3D 素材（猫/人台/石膏像）
+ 水青色渐变小球点缀 + 星芒贴纸。信息图黑白为主, 青色提亮。风格高辨识度、年轻。

| Token | Value | Use |

Type: 英文大词 + 中文黑体; 章节卡 "One. Two. Three." 白卡黑描边。
本模版的 3D 铬素材可用素材工厂复刻: prompt "holographic chrome 3D object, iridescent
metallic, pure white background" + cutout.py 抠图。
