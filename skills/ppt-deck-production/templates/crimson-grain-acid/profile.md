# crimson-grain-acid — 绯红弥散酸性

Source: 小夕素材(21).pptx · 20 slides · 16:9. 中文商务模版（占位符为中文）。
绯红噪点弥散渐变全幅底 + 黑色四角星芒 ✦ + 细线网格与年份角标 + 金属银花摄影；
白底内容页用黑描边盒子 + 红色信息图。潮流酸性但信息密度友好。

## Design tokens

| Token | Value | Use |
|---|---|---|
| `--crimson` | `#AC595C` | 弥散渐变主色 |
| `--crimson-deep` | `#84393B` | 渐变暗部, 强调色 |
| `--mauve` | `#C3ADAC` | 渐变亮部/灰粉过渡 |
| `--paper` | `#FFFFFF` | 内容页底 |
| `--ink` | `#111111` | 星芒、描边、正文 |
| `--chip-black` | `#000000` | 黑底白字小标签 (BUSINESS / 2022) |
| grain | 噪点颗粒叠加在渐变上 | 封面/章节页 |
| photo treatment | 金属银质感花卉/静物 | 点缀图 |

Type: 大写英文展示词 + 中文黑体标题; 章节大数字 "01." 黑色特大。
Chrome: 页面四周细线框/十字线 + 左上黑чип标签 + 侧边年份竖排 "2022/09"。

## 推荐三级字体方案（fonts/ 库）

- 封面: 站酷酷黑（或 联盟起艺卢帅正锐黑体） · 标题: 优设标题黑 · 正文: 阿里巴巴普惠体
